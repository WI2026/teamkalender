Team und Zugänge

Jede Person bekommt einen Einmal-Code und legt damit ihr eigenes Passwort fest. Gib den Code nur der Person selbst, persönlich oder als Direktnachricht. Er gilt einmal und 7 Tage.

  1. Bei deinem Namen „Verwalten an“ tippen. Fehlt dein Name, lege dich unten an und setze dabei das Häkchen „darf das Team verwalten“.
  2. „Code erzeugen“ tippen und den Code notieren.
  3. Abmelden, „Zum ersten Mal hier?“ wählen und mit dem Code dein eigenes Passwort festlegen.
  4. Danach erzeugst du die Codes für alle anderen und schaltest das Team-Passwort ab.

    Das Änderungsprotokoll sehen nur Personen mit Verwalter-Recht. Wer wann was geändert hat, steht dort zwölf Monate lang.

    Das gemeinsame Team-Passwort funktioniert noch. Wenn alle ihr eigenes haben, schalte es ab. Wer es kennt, kommt danach nicht mehr hinein.
